## 双航迹接力预演

在主栏「接力布置」中选择两份已保存航次：

1. 第一份是当前/交棒艇的预演航迹；实赛仍由玩家亲自驾驶，不会用预演轨迹代替实际船态。
2. 第二份是接棒艇在玩家接管前沿行的记录。正的出发偏移表示该记录相对比赛钟延后开始，`记录时间 = 比赛时间 - 偏移`。
3. 偏移输入支持 `0.001s` 数值和连续滑杆，也可以直接在偏移图上拖动；出发后锁定这一次偏移。
4. 纯函数分析位于 `src/features/relay/lib/analyze.ts`。它先在零偏移时间线上找分离的近遇段，再围绕每个近遇连续扫描/二分偏移边界，并用插值样本核对距离、速差、航向差、R1 指定水域和持续时间。
5. 绿色粗条是远离阈值端点的「可确认范围」；黄色菱形是临界估计，橙色虚线括号和 `临界未定` 标签表示保存样本不能在预演中定死的边。所有临界值都必须在实赛重新确认。
6. 出发后 `useRelay.tick()` 只使用玩家艇的实际状态和接棒艇当前记录状态重新计算。所有条件连续保持达到设定秒数后才交棒；接管时复制接棒艇当时的位置、船首向、航速、帆角和舵态，裁判进度按第二份记录的已过门同步，交棒事件与接力成绩使用实际比赛时刻。

没有现成航次时，可点击「载入示例航迹」。该夹具包含两次近遇：较早一次有 6.81s 运动并行但完全不在 R1 水域；较晚一次只产生一个位于整秒之间的区间，当前预演值为临界边 `+1.149s … +1.878s`、可确认范围 `+1.179s … +1.848s`。这些数字来自内置夹具；选择真实 localStorage 航次后会按其样本重新计算。
